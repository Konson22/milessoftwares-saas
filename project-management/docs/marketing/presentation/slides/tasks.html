Tasks on a board or a timeline

Tasks are numbered to their project (WASH-12). A task can’t be marked done while one it waits on is open, and circular dependencies are refused.

Left: the board, where cards are dragged between columns or reordered. Right: the timeline, with tasks drawn from start to due, milestones as diamonds and a line for today. There is also a plain list view. Each task carries priority, assignee, milestone, estimate, subtasks, checklist, comments, attachments and time logged.
